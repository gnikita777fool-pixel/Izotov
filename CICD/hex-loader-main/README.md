# 🚀 Hex Loader (Go + Fyne)

**Hex Loader** — это кроссплатформенное GUI-приложение для загрузки HEX-файлов в платы Arduino, написанное на Go с использованием фреймворка Fyne. Приложение использует `arduino-cli` под капотом.

## 📋 Особенности проекта
- Кастомная тема Fyne (увеличенный шрифт, специфические цвета, отсутствие теней).
- Кастомные кнопки с нарисованной обводкой (border).
- Автоматическое определение подключенных плат и портов.
- Удобный диалог выбора FQBN (Fully Qualified Board Name) с популярными пресетами и ручным вводом.
- Проверка прав доступа к последовательным портам (группа `dialout` / `uucp`).
- Сохранение последнего выбранного пути к HEX-файлу в `preferences`.

## 📥 Установка и запуск

### Требования
- Установленный `arduino-cli` (должен быть доступен в `PATH`).
- Установленные ядра Arduino (например, `arduino-cli core install arduino:avr`).
- Права на чтение/запись последовательных портов (в Linux добавьте пользователя в группу `dialout`: `sudo usermod -a -G dialout $USER`).

### Запуск
1. Скачайте архив или бинарник для вашей ОС из раздела [Releases](../../releases).
2. Распакуйте и запустите исполняемый файл `HexLoader`.
3. Выберите `.hex` файл, укажите порт и нажмите **⬆️ Загрузить**.
